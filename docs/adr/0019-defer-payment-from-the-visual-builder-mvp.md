# Defer payment and Hosting entitlements from the visual-builder MVP

The visual-builder MVP does not implement Midtrans, Payment records, Hosting entitlements, renewal, refund, chargeback, or payment-gated publication. An Owner may publish a valid Draft directly so that the first release validates the visual editor and public Invitation experience without payment infrastructure.

Future payment work may add a publication prerequisite at the application boundary. It must not be embedded in the Design document, editor command model, or renderer.
