# Use a structured visual canvas for the MVP

Vowly's MVP uses a direct visual editor inspired by Figma and Webflow, but the published Invitation is represented as a structured responsive Design document. Owners can select, insert, move, duplicate, hide, delete, and style Sections, Containers, Grid layouts, and typed Content blocks. Grid layouts use bounded one-, two-, and three-column presets that reflow on smaller viewports.

The editor does not support arbitrary pixel-coordinate placement, vector drawing, unrestricted nested layout, arbitrary HTML/CSS/JavaScript, or user-authored animation timelines in the MVP. This preserves predictable responsive rendering and keeps the editor focused on wedding Invitations rather than becoming a general graphics application.
