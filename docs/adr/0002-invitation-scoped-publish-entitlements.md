# Future: scope publish entitlements to one Invitation

When paid publication is introduced, each Vowly Publish — 1 Year purchase should create or renew the Hosting entitlement for exactly one Invitation. The entitlement should not be account-wide, transferable, or pooled.

This decision is future commercial design and is not implemented in the visual-builder MVP. The current MVP allows an Owner to publish a valid Draft without payment or a Hosting entitlement.
